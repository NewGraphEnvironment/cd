## Outcome

`pipeline_update_edh.R` STEP 5 built `catalog.json` from only the COGs that run had rewritten, then pushed it over the live catalog. Any COG skipped in STEP 4 therefore dropped out of the published catalog while its `.tif` stayed on S3 unreachable, and the run still exited 0. Both pipelines now run one shared guard (`publish_problems()` / `catalog_problems()` in `scripts/_lib.R`). It requires all 59 COGs, nothing else in the directory, and one contiguous span of years covering the live years; it checks the written catalog before the push and the live one after it. The update path also checks the live catalog's keys and years in STEP 1, so a broken catalog fails within seconds, and the weekly dry run reports it too. Strict refusal was chosen over merging new items into the live catalog, because a merge lets a skipped variable lag a year behind with nothing to show it. The plan review found the less obvious bug: `cd_s3_push()` syncs `--size-only`, and a healthy update changes `catalog.json` only from `2025-12-31` to `2026-12-31`, which is the same byte length, so the rebuilt catalog would never have been uploaded. It is now uploaded on its own with `aws s3 cp`, after the COGs. Review rounds: plan review, round 1 (trusting the record of a write over the file on disk), round 2 clean, round 3 (a failed catalog upload leaving the catalog a year stale on green runs, a defect inside the upload fix). The loop ended by enumerating every guard exit and what it reads (`findings.md`). The partial-sync repair went to #119.

## Measurement

The live catalog was measured at 59 items, all spanning 1950-2025, with seasonal band names matching annual. That confirmed the "one span across all 59" invariant before it was enforced. The offline checks run 54/54, and each guard branch was confirmed by mutation to turn its test red (table in `findings.md`). The interop run (59 tiny COGs through the real `cd_stac_catalog()`) gave 0 problems healthy, and both guards named a single removed file. The dry run exits 0 and logs `Live catalog: the expected 59 items, 1950-2025`. STEP 4-5 cannot run end to end until 2026 lands on EDH (~Feb 2027).
